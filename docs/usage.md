# 使用指南

### 界面语言

右上角选择中文或 English。首次打开按浏览器语言匹配，后续优先使用本机保存的选择；没有匹配语言时使用中文。切换语言不会刷新页面或清空输入、处理结果和画布设置。代码内容、窗口标题和已有结果保持原样，代码高亮语言仍在画布的语言菜单中单独选择。

### 常用操作

| 操作         | 方式                                            |
| ------------ | ----------------------------------------------- |
| 搜索工具     | 首页输入关键词，或按 `/` 聚焦搜索框             |
| 执行文本处理 | 在输入或结果区域按 `Ctrl + Enter` / `⌘ + Enter` |
| 试用工具     | 点击「加载示例」，已有输入时会先确认替换        |
| 保存结果     | 使用复制或下载按钮；代码画布支持直接复制图片    |

刷新页面会清除自行输入的内容；代码画布页面会恢复公开示例，但保留本机外观偏好。需要保留结果时，请先复制或下载。

## 代码编辑

JSON、SQL 支持语法高亮、行号和自动换行，结果区只读。`Tab` 缩进、`Shift + Tab` 取消缩进，按 `Esc` 后再按 `Tab` 可离开编辑器；`Ctrl / ⌘ + F` 查找，`Ctrl / ⌘ + Z` 撤销编辑。加载示例和清空会重置撤销历史。

超过 200,000 字符时自动暂停高亮，保留编辑、复制和下载能力。

## 隐私与使用说明

工具处理逻辑在浏览器内运行，代码图片也在本地生成。网站仍需加载静态资源；如果启用 Umami，还会发送页面访问及工具使用事件。

统计载荷按白名单生成，只包含必要的页面信息、工具 ID、动作、成功／失败和枚举错误类别，不包含输入、输出或错误原文。URL 查询参数与 hash 会被排除，来源地址只保留 origin，并尊重浏览器的 Do Not Track 设置。

### 输入格式与处理范围

| 工具     | 使用说明                                                                                                |
| -------- | ------------------------------------------------------------------------------------------------------- |
| 文本工具 | 输入上限为 5 MiB（UTF-8）；处理超过 8 秒会终止，可拆分后重试                                            |
| JSON     | 最多嵌套 128 层；格式化输出最多 20 × 1024 × 1024 个 UTF-16 代码单元；重复键需修正后再转换               |
| 时间戳   | 日期格式为 `YYYY-MM-DD HH:mm:ss`；明确选择秒／毫秒与时区，本地时间有夏令时歧义时请使用 UTC              |
| JWT      | 解析三段式 Token；签名未经验证，时间状态依据当前设备时钟                                                |
| SQL      | 提供排版结果；查询在目标数据库中的可执行性需另行验证                                                    |
| JSON 转类型 | 根据样例推断 TypeScript 或 Java 类型；对象数组会合并字段，混合元素在 Java 中以 `Object` 表示 |
| Cron     | Linux 使用 5 字段，Quartz 使用常用 6 字段；支持数字、通配符、范围、列表和步长，搜索未来 5 年            |
| 代码画布 | 最多 12,000 字符、160 行；语法高亮超时为 3 秒，图片上限为 1600 万像素及 12,000 像素高度；支持指定宽度和长行自动换行 |

Quartz 的日与周字段必须恰有一个 `?`，星期为 1（周日）至 7（周六）；Linux 的周日为 0 或 7，日与周同时受限时采用 OR 匹配。搜索范围内没有结果，不代表表达式永不执行。

代码画布只在本机保存经过校验的主题、背景、字体、字号、行高、边距、宽度、倍率及开关设置，不保存代码、语言搜索或窗口标题；可通过「恢复默认外观」重置，存储不可用时仍可正常使用。

代码画布支持 28 种语言与格式，顶部语言菜单内可搜索并按用途分组，每种语言都提供对应示例；切换语言保留当前代码，点击「加载示例」才会替换，已有内容时先确认。主题和背景可在工具栏直接切换；六套风格预设位于「外观设置」内，其他选项分为窗口、编辑器、布局三个分组。桌面端设置区在右侧展开，手机端在画布下方展开，各自滚动。代码直接在成品画布中编辑，标题可在窗口顶部修改。支持 Tab 缩进、撤销和查找，导入 Windows 文件会统一换行符以保证查找位置正确。自动画布至少 800 px 宽，随代码自然增高；桌面默认适应宽度，长代码在工作区内纵向滚动，不因高度变长而缩小代码。手机端默认适应画布。还可选择 50%、75%、100% 和 150% 缩放，不改变 PNG 导出尺寸。Vue 使用 HTML 及内嵌脚本、样式规则高亮；纯文本无需高亮线程即可使用。

宽度默认为自动；指定宽度可选 640、800、1200 px 或自定义 320–2400 px（整数），包含外边距，按 1× 计算。指定宽度默认开启长行换行，续行不重复行号，源码不变；关闭换行时，超宽内容会明确报错，不裁切代码。换行由浏览器统一排版，代码中的空格、Tab 和空行保持不变。换行后的图片仍受像素和高度限制。下载文件使用本地日期时间及毫秒命名，例如 `wind-code-20260918-143025-128.png`。

代码图片内置 JetBrains Mono 与 Source Code Pro，也可选系统等宽字体；提供紧凑、舒适、宽松三档行高。字体文件由本站提供，无需第三方字体服务。中文及未覆盖字符使用系统字体回退，跨设备可能略有差异，Tab 显示为四个空格。复制图片需要安全上下文与浏览器剪贴板支持，失败时可下载 PNG。

编辑内容直接显示在画布上。导出复用同一份画布内容，自动排除光标、选区、查找面板与输入控件；字体与当前代码高亮准备好后才开放导出。清空后可直接在画布上继续输入。

工具栏提供直接复制图片和下载 PNG 的按钮。导出菜单显示实际尺寸，支持切换 1× / 2× / 3×；PNG 超过像素或高度上限时，菜单仍可打开以降低倍率，SVG 不受 PNG 倍率上限影响。

桌面端可通过左上角按钮收起侧边栏，仅保留工具图标，将空间留给内容。展开状态仅保存在本机，切换不会清空当前输入。手机端通过左上角打开工具导航，点击关闭、菜单外区域或按 Esc 可退出。

桌面侧栏闲置 30 秒后自动收起；鼠标停留或键盘焦点在侧栏内时保持展开。可点击「固定展开」关闭自动收起，固定偏好保存在本机。自动收起不会改变手动展开偏好，手机抽屉不受影响。
